🏡 Help Nest
A Cooperative & Gig Services Platform for Household & Community Services

📖 Overview
Help Nest is a platform designed to connect households and communities with trusted service providers. It enables cooperative engagement and gig-based work opportunities, fostering collaboration, convenience, and empowerment at the local level.

The project aims to:

Simplify access to household and community services.

Provide fair opportunities for gig workers and cooperatives.

Build trust through transparent service listings and reviews.

🚀 Features
🔍 Service Discovery: Browse and search for household and community services.

👥 Cooperative Model: Encourage community-driven service sharing.

💼 Gig Opportunities: Allow individuals to offer services flexibly.

⭐ Ratings & Reviews: Build trust with transparent feedback.

📱 Responsive UI: Accessible across devices with a clean interface.

🛠️ Tech Stack
Frontend: React.js
Backend: Node.js / Express
Database: MongoDB
Deployment: Google Cloud Run
Version Control: GitHub
